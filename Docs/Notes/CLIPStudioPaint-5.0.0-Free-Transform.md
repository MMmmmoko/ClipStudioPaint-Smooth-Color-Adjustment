## 命令与交互

1. **命令注册**读取 `editactiontransformfree`，构造时绑定命令 ID `0x000D0025`。**模式转命令名**的跳转表将模式值 `4` 映射回该字符串。自由变换命令执行分支构造同一命令 ID，把值 `4` 传给 `Begin`。这里的 `4` 是操作模式。后文的 `2` 是几何表示类型。
2. **变换工具构造**通过虚表关联到 RTTI 的 `PWTransformTool`。**会话模式初始化**保存收到的模式值。入口在已有变换会话时也可以走模式更新，**操纵器模式写入**将新的模式同步写入操纵器的两个模式字段。5.0.0 的实测会话以通用模式 `1` 打开。不按 Ctrl 拖动角点及框内平移时，有效模式仍为 `1`。按住 Ctrl 拖动角点时，操纵器临时使用模式 `4`。
3. `PWResizableImageObjectManipulator` 的拖动事件读取当前变换状态、手柄编号和修饰键。实测不按 Ctrl 拖动角点时，原生缩放保持对角固定，移动其余三个角。按 Ctrl 进入**四角拖动**路径时，角手柄替换单个角的 X、Y 坐标。这条路径的边中点手柄用「指针位置 − 边中点」得到位移，再将位移加到同一条边的两个角上。
4. **写入四角**在适用条件下先尝试求解四点映射，通过后将四个双精度坐标对写回 `PWResizableImageInfo` 的控制点序列，并更新变换状态。**四边形检查**用相邻边的叉积判断转向是否一致，对叉积为零或转向不一致的点组返回失败。**四点求解**对输入的两组角点都执行这项检查。这解释了为什么试图把角拖成凹四边形、自交形状或共线的退化形状时，受检查的更新分支会拒绝该状态。

## 栅格几何与重采样

**栅格应用分派**按几何类型选择实现。类型 `2` 的四边形路径经`QuadCall`把两组角点、质量参数及图像对象交给四边形重采样函数。分派还对部分没有四角改动的状态使用较简单的路径。网格与 Puppet warp 在命令层和几何分派层都有各自的分支。

**四点求解**将四对点展开为八条线性方程，求八个系数。对于栅格反向采样，将每个目标点记为 `(x, y)`，对应的源点记为 `(u, v)`，则有：

```text
w = g*x + h*y + 1
u = (a*x + b*y + c) / w
v = (d*x + e*y + f) / w
```

这是一张平面单应矩阵。分母中的 `g`、`h` 可以随位置改变，使矩形映射到一般凸四边形，保留直线并产生透视缩短。**映射单点**以双精度计算该式，并在分母落入约 `[-1e-8, 1e-8]` 的范围时返回失败。

四边形重采样函数求目标区域并遍历输出图像块，根据质量参数和像素格式分派到不同采样实现。已追到的**定点像素循环**把矩阵系数换成定点量，沿输出扫描线递增分子及分母。每个输出像素用同一分母做两次有符号整数除法，得到源图 X、Y，再将整数和小数部分传给采样函数。分母为零时跳过该像素的采样调用。另一个分支直接以整数源坐标读取像素。

这里的「双线性」是源图亚像素颜色的插值方式。拖动后坐标落在哪里由单应矩阵决定，插值方式决定怎样从该位置周围的像素取色。本机英文变换面板资源列出双线性、最近邻、双三次、平均颜色和过采样。图层类型及当前操作可以影响可用选项。[CELSYS 手册 · 插值方式](https://help.clip-studio.com/en-us/manual_en/810_subtools/I.htm)

## 预览、确认和取消

- **拖动时**，角点事件经 `Drag` / `DerivedDrag`，分别按当前模式走原生缩放或四角变形。按住框内平移经 `Move` / `DerivedMove`，事件携带 X、Y 位移，并使用不同的阶段和脏区字段。派生类 `PWTransformObjectManipulator` 先调用基础回调，再更新参与变换的图层并补齐脏区。释放回调通过 `CanvasRefresh` 把脏区转换为画布视图坐标，同时标记图像缓存和画布控件失效。
- **结束时**，画布控制器的两个入口分别以 `0` 和 `1` 调用`End`。分派释放会话中持有的临时状态，并按标志和会话状态选择后续处理。**确认后的应用路径**枚举图层对象并调用文档应用路径。RTTI 可区分单图层和多图层的变换命令对象。**单图层命令构造**、**多图层命令构造**对应各自的虚表，说明图层变换有专门的命令对象管理。手册确认 Enter 或 OK 接受变换，Esc 或 Cancel 丢弃当前变换。[CELSYS 手册 · 确认与取消](https://help.clip-studio.com/en-us/manual_en/360_transform/Types_of_transformations.htm)
- **保留原图**和**更改矢量线宽**都在本机变换面板资源中。手册描述前者保留选区的副本，后者适用于矢量图层。以上像素循环是栅格路径。矢量对象也有独立的 `PWVectorObjectManipulator` 拖动路径，其**矢量四点求解调用**使用同一个单应求解器。尚未核实矢量曲线和笔宽如何随单应变换重建。[CELSYS 手册 · 工具属性](https://help.clip-studio.com/en-us/manual_en/360_transform/Transform_using_the_Tool_Property_palette.htm)

## CSPMOD 的预览路径

自由变换开始后记录原生会话，确认或取消前清空会话。原程序继续求解矩阵、遍历输出图块和合成画布。命中已验证的栅格采样调用时，CSPMOD 从原程序准备好的离屏源视图读取颜色和透明度，按原生采样器准备好的目标视图和图块坐标裁剪源范围，用 D3D11 计算着色器执行反向投影，再把结果写入原程序的颜色、透明度平面。每次原生采样批次只派发一次计算和一次读回。

GPU 路径支持三字节或四字节颜色平面，配合独立的 8 位透明度平面。每个采样批次的目标区域为 16 Ki 至 8 Mi 像素。最近邻和双线性沿用各自的采样方式。高精度模式在鼠标按住时可以用 GPU 双线性出预览，其他时候按原插值出图。像素格式、标志、面积或设备不满足条件时，由原采样函数处理。确认和取消前退出加速，确认仍使用选定插值。GPU 浮点投影在像素边界可能与原有定点循环有取整差异。

GPU 写回完成采样后，画布仍需合成并呈现。CSPMOD 在角点回调更新几何后请求刷新，涵盖单角变形和原生缩放。框内平移在专用位移回调更新图层位置后请求刷新。基础回调被派生回调调用时，只在派生回调结束后请求刷新，确保图层位置和脏区都已更新。预览合并待刷新的区域，以不短于 16 ms 的间隔调用原生画布刷新入口。松开时仍走原生刷新流程。若任何所需特征失效，禁用整组自由变换优化。

## 验证

使用同一个生产定位器读取两个原始 PE，两版均唯一定位 24 个条目。分别在内存映像中破坏开始、基础或派生拖动、基础或派生平移及刷新入口的序言，并单独复制四边形调用特征。定位器均返回失败、报告特征名并丢弃整组结果。功能测试只使用指定安装目录的 5.0.0。

2400 × 1800 的合成彩色栅格用于验证实际预览。早期仅做 GPU 写回时，用户提供的 2026-11-11 16-59-11 录像约 4.7–5.7 秒可见控制框移动而棋盘图案停在上一帧。用户在 5.0.0 分别手动确认框内平移、按 Ctrl 拖动单角，以及不按 Ctrl 拖动角点并带动三个点时，画布像素都能在松手前连续更新。不按 Ctrl 的实测拖动中，原生缩放在模式 `1` 更新脏区，四边形采样调用数为零。按 Ctrl 拖动时，同一手柄进入模式 `4`，四边形采样调用数开始增长。
